# Archived research Sites

These static reading aids were created during the research. The research-options Site originally used private Sites hosting; this repository publishes its static source because public sharing was authorized for the research repository. No hosting identifiers, private browser state, or access credentials are included. A live Sites deployment is not required to read the source or preview it locally.

The comparison Site quotes passages from an earlier reference paper, so its page references and “final paper” labels may differ from the current [`../paper/BenShabtay_Paper.pdf`](../paper/BenShabtay_Paper.pdf). The research-options Site preserves earlier exploratory decisions and candidate results. Neither Site replaces the submitted paper or validates all archived analyses.

Preview either from the repository root:

```bash
python3 -m http.server 8766 --directory sites/study-options/dist
# Open http://localhost:8766
```

```bash
python3 -m http.server 8767 --directory sites/paper-comparison/dist
# Open http://localhost:8767
```

No dependencies or build step are needed. Original articles remain linked to their publisher/public host rather than republished as PDF downloads.
